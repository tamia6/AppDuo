# AppDuo icon concepts

Four original concepts:

1. `01-blue-windows.png`: blue twin windows.
2. `02-violet-loops.png`: violet paired loops.
3. `03-teal-spaces.png`: two complementary teal workspaces.
4. `04-coral-leaves.png`: warm coral twin leaves.

Selected: concept 1 with the mint palette (`palette-variants/01-mint.png`).
This image is the source for the app's production `AppIcon.icns`, containing
standard macOS icon sizes from 16 px through 1024 px.
The indigo and apricot palette variants remain as design references.
