Multiple WeChat accounts on Mac with AppDuo

Create distinct WeChat identities on macOS with custom names, icons and data directories. Learn setup requirements and compatibility limits.

AppDuo is a free, open-source macOS app cloner. Hard clones copy the source app and provide separate names, icons and data paths for personal and work identities. Compatibility can vary between WeChat versions.

Requirements

  • macOS 14 or later, with the original WeChat installed and working.
  • Download AppDuo from GitHub Releases: arm64 for Apple Silicon, x86_64 for Intel.
  • Creating clones requires Apple Command Line Tools. If needed, run xcode-select --install and complete the system installer.
  • Current packages are not Apple-notarized. Use the official release and check its source; do not globally disable system security.

Create an identity

  1. Open AppDuo, start creating a clone and select the installed WeChat application. The AppDuo UI is currently Chinese.
  2. Choose a hard clone and a name such as WeChatHK. Use a separate data directory for each identity.
  3. Optionally select an .icns icon. Without a custom icon, the source app icon is used.
  4. Review the settings and create the clone. Open it from its card and sign in to the intended account.
  5. Repeat with another name and data directory for another identity.

Verify the result

Open the original and clone together and check each account, icon and application path. If the clone opens the original app, check the saved clone path and use the latest AppDuo release. Separate directories are not a complete security sandbox and do not guarantee that the target app shares no system resources such as Keychain items.

Login and multi-instance compatibility are not guaranteed for every WeChat version. Report your macOS, AppDuo and WeChat versions and cloning mode when filing an issue; do not include credentials or private messages.
