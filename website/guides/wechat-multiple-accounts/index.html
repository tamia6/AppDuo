Mac 微信多开：用 AppDuo 区分工作与私人账号

在 Mac 上创建具有不同名称、图标和数据目录的微信分身，了解安装要求、创建流程与兼容性限制。

AppDuo 是免费开源的 macOS 应用分身工具。硬分身复制原应用，并为分身提供不同的名称、图标和数据路径，适合区分工作与私人账号。不同版本的微信可能存在兼容性差异。

开始前准备

  • macOS 14 或更高版本；先安装并正常运行原版微信。
  • 从 GitHub Releases 下载对应架构的 AppDuo：Apple Silicon 使用 arm64，Intel 使用 x86_64。
  • 创建分身需要 Apple Command Line Tools。未安装时在终端运行 xcode-select --install，完成系统安装提示。
  • 当前安装包未经过 Apple 公证。应从项目官方 Release 获取，核对来源；无需为此全局关闭系统安全保护。

创建一个独立身份

  1. 打开 AppDuo，点击新建，选择已安装的微信应用。
  2. 选择硬分身，设置名称，例如 WeChatHK。选择独立的数据目录；不要把不同身份指向同一个目录。
  3. 按需选择自定义 .icns 图标。没有自定义文件时使用原应用图标。
  4. 确认配置后创建，再从该分身卡片点击“打开”，在新窗口中登录对应账号。
  5. 需要另一个身份时重复上述流程，使用不同名称和数据目录。

如何确认创建成功？

同时打开原应用和分身，检查各自账号、图标和应用路径。若点击分身却打开原应用，先检查卡片记录的路径是否指向生成的分身，并确认使用最新 AppDuo 版本。独立目录不等于完整安全沙箱，也不保证目标应用不会共享钥匙串等系统资源。

本文不承诺所有微信版本均可登录或多开。遇到问题时记录 macOS、AppDuo、微信版本和分身方式，再向项目提交反馈；不要公开账号、密码或聊天记录。
