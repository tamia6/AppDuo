微信分身如何分别接收 macOS 通知

查看原版微信与分身的真实通知截图，设置通知权限，并排查专注模式、运行状态和应用兼容性问题。

在目标应用兼容、权限允许的情况下，微信原应用和 AppDuo 分身可以分别接收各自账号的通知。AppDuo 不提供推送服务，也不保证退出应用后仍能通知。

真实通知示例

用户提供的截图显示两个微信实例的通知。通知来源名称可能显示会话名称或应用名称，具体取决于微信及 macOS 的注册结果。

开启与验证

  1. 分别打开原版微信和分身，确认登录的是不同账号。
  2. 在每个账号的应用内设置中开启新消息通知，确认会话没有被静音。
  3. 在 macOS“系统设置 → 通知”中检查对应应用条目并允许通知；同时检查横幅、声音和预览设置。
  4. 检查专注模式是否屏蔽提醒。测试时保持应用运行。
  5. 给各账号分别发送一条非敏感测试消息，核对收到通知的应用图标及账号。不要仅凭图标推断消息隔离成功。

收不到分身通知时

  • 先确认原应用通知正常；再核对分身应用内及系统权限。
  • 若分身由较旧版本 AppDuo 创建，正常退出后尝试用新版更新分身。更新通常保留配置、图标和数据；重要数据应自行备份。
  • 优先使用应用规则默认的自动注入方式。显式 launcher 模式或需要特殊启动参数的应用可能存在通知兼容限制。
  • 记录 macOS、微信与 AppDuo 版本、分身模式及是否能复现，再提交问题。截图先去除私人消息。

不同微信版本可能改变通知实现；本例不能证明所有应用或所有版本都兼容。三个身份的方案需要分别完成同样的授权和测试。
